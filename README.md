# 🏴‍☠️ Post Pirate

> **Verified Government Job Discovery & Vacancy Prediction Engine for SBTET Telangana Diploma Engineers**

Post Pirate is a zero-cost, mobile-first web platform built to eliminate fake job circulars and streamline employment discovery for polytechnic and diploma students across Telangana. Calibrated for the **SBTET C-24 Curriculum**, Post Pirate matches diploma branches and minors with verified central, state, PSU, and defence opportunities.

### 🌟 Key Highlights
- **Curriculum-Accurate Matching**: Direct support for SBTET engineering branches and C-24 minor specializations.
- **Built-in Relaxations**: Automatic category-based age and fee relaxation calculations (SC/ST/OBC/EWS/PwD).
- **Vacancy Prediction Engine**: Projects recruitment notification windows based on historical gazette cycles.
- **Strict Verification Standard**: Only verified postings directly sourced from official gazettes and portals (SSC, TGPSC, RRB, DRDO, ISRO).
- **Zero-Cost Automation**: Runs 100% free with automated nightly data self-healing via GitHub Actions and static CDN hosting via GitHub Pages.
